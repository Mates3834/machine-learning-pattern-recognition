# Machine Learning and Pattern Recognition

Generic Python implementations of classical machine-learning and pattern-recognition methods.

Topics covered:
- Class-wise mean vectors and covariance matrices
- Gaussian statistical classification
- Two-feature decision-boundary analysis
- Principal Component Analysis (PCA)
- K-Means clustering
- Agglomerative hierarchical clustering
- Cluster-cost evaluation
- Synthetic-data experiments

The repository is organized as a clean public portfolio implementation and does not reproduce course-specific submission files.
